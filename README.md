# SELF • SENSE — сайт модельного агентства и школы моделей

Готовый сайт для **GitHub Pages**: без сборки, без сервера, без платных сервисов.
Весь контент (тексты, цены, курсы, модели, фото, видео) хранится в `content/content.json`
и редактируется через встроенную админку `/admin/`.

---

## 1. Публикация на GitHub (один раз, ~5 минут)

1. Создайте на GitHub новый **публичный** репозиторий, например `self-sense`
   (для бесплатного GitHub Pages репозиторий должен быть публичным).
2. Загрузите в него **содержимое этой папки** (файлы `index.html`, `.nojekyll`, папки `assets`, `content`, `media`, `admin` и т.д. должны лежать в корне репозитория).
   - Проще всего через **GitHub Desktop**: *File → Add local repository →* выберите эту папку → *create a repository* → **Publish repository** (снимите галочку *Keep this code private*).
   - Или на сайте GitHub: *Add file → Upload files* и перетащите все файлы и папки.
3. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/self-sense/`.

Дальше всё работает само: любая правка в админке — это коммит в репозиторий, и GitHub Pages пересобирает сайт автоматически (30–90 секунд).

> Свой домен: Settings → Pages → Custom domain. После этого в админке при входе укажите логин и имя репозитория вручную.

## 2. Админка

Адрес: `https://ВАШ-ЛОГИН.github.io/self-sense/admin/`

**Токен (один раз):**
1. GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. *Repository access* → **Only select repositories** → выберите репозиторий сайта.
3. *Permissions → Repository permissions* → **Contents: Read and write**
   (по желанию **Pages: Read** — тогда админка покажет, когда сайт обновился).
4. Скопируйте токен и вставьте в админке. Логин и репозиторий подставятся сами.

Токен хранится только в вашем браузере. Потеряли устройство — просто удалите токен на GitHub.

**Что можно редактировать — всё:**
- общие настройки: логотип-текст, цвета, прелоадер, курсор, SEO и картинку для соцсетей;
- контакты, меню, порядок и видимость каждой секции;
- главный экран (3 видео), философию (с фото прямо в тексте), ценности, бегущую строку;
- курсы: цены, длительность, программы, фото;
- каталог моделей: добавление/удаление, параметры, описание, теги, фото (перетаскиванием меняется порядок, первое фото — обложка);
- кампании брендов, съёмки портфолио, онлайн-продвижение, доп. услуги, блок 60+/70+, галерея, FAQ;
- форма записи: дни и время пробных уроков, тексты, куда приходят заявки.

Фото загружаются прямо из админки: она сама уменьшает их до 1600 px, делает миниатюры и кладёт в `media/`.
Видео — MP4 (H.264), 5–15 секунд, до 45 МБ; обложка создаётся автоматически.
Формат HEIC (iPhone) браузеры обычно не читают — сохраните фото как JPG.

Кнопка **«Предпросмотр»** показывает сайт с неопубликованными правками. **«Опубликовать»** (или Ctrl+S) — сохраняет всё одним коммитом.

## 3. Заявки с сайта

На сайте 5 форм: пробный урок (с выбором даты и времени), заявка в базу моделей, съёмка портфолио, онлайн-курс для иногородних, приглашение модели на съёмку.

Админка → **Запись и заявки → Куда приходят заявки**:
- **Web3Forms (рекомендуется):** на [web3forms.com](https://web3forms.com) введите почту → получите Access Key → вставьте в админке → способ «Web3Forms». Заявки приходят на почту, бесплатно.
- **Formspree** — аналогично, по ID формы.
- **Без сервера** (по умолчанию): при отправке открывается WhatsApp / Telegram / почта с готовым текстом заявки — номер и ники берутся из «Контактов».
- **Telegram-бот** — работает, но токен бота будет виден в коде сайта.

## 4. Что заменить перед запуском

- **Контакты** — сейчас стоят заглушки (телефон, почта, ники).
- **Модели** — имена и параметры (рост, размеры, год рождения, описание) заполнены примерно для демонстрации. Проверьте каждую карточку.
- Ссылки на галереи wfolio «Алиса» и «Полина» на момент сборки были просрочены — эти фото не загружены; их можно добавить через админку.

## 5. Локальный просмотр

```
python -m http.server 8000
```
и откройте `http://localhost:8000`. (Открывать `index.html` двойным кликом нельзя — браузер не даст загрузить `content.json`.)
Админка локально работает в режиме «без GitHub»: правки сохраняются в скачиваемый `content.json`.

## Структура

```
index.html            — страница сайта
content/content.json  — ВЕСЬ контент сайта
assets/css, assets/js — стили и анимации (GSAP + ScrollTrigger + Lenis, лежат локально)
assets/fonts          — шрифты Cormorant Garamond и Manrope (кириллица)
media/img, media/thumb, media/video, media/brand — фото, миниатюры, видео, логотип
admin/                — админка
```
