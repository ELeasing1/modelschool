Как получить токен?
  1. GitHub → аватар → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → выберите репозиторий сайта.
  3. Permissions → Repository permissions → Contents: Read and write (по желанию ещё Pages: Read — чтобы видеть статус публикации).
  4. Скопируйте токен и вставьте сюда. Токен хранится только в этом браузере.
